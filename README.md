# 🔢 제타 원문 글자수 카운터

웹 제타(zeta-ai.io) AI 답변 원문 글자수 보여주는 유저스크립트임

- 버전: **1.0.0**
- 만든 사람: 제타 여성향 갤러리 ㅇㅇ

---

## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| 🔢 원문 글자수 | 답변 아래 🔢 누르면 공백 포함 · 제외 글자수 뜸 (수정창 기준) |
| ✏️ 실시간 글자수 | 메시지 수정할 때 글자수 실시간으로 뜸 |
| 💾 유지 | 채팅방 나갔다 와도, 새로고침해도 그대로 |
| 🎭 꾸미기 | 아이콘 바꾸기 · 위치 옮기기 · 고정 (🔢 오른쪽 클릭) |

---

## 📥 설치 방법

### 1. 템퍼몽키 설치
브라우저에 **Tampermonkey(템퍼몽키)** 확장 프로그램 설치
- 크롬 · 엣지 · 웨일: 확장 프로그램 스토어에서 "Tampermonkey" 검색
- 파이어폭스: 부가 기능에서 "Tampermonkey" 검색

### 2. 유저스크립트 허용 켜기 (크롬 계열만)
요즘 크롬은 템퍼몽키 깔아도 이거 안 켜면 스크립트가 안 돌아감 (제일 많이 놓치는 부분)
1. 주소창에 `chrome://extensions` 입력 (엣지는 `edge://extensions`)
2. Tampermonkey **세부정보** 누르기
3. **사용자 스크립트 허용** 켜기

> 옛날 버전 크롬은 이 스위치가 없음 → 확장 프로그램 페이지 오른쪽 위 **개발자 모드** 켜면 됨

### 3. 스크립트 설치
아래 링크 누르면 템퍼몽키 설치 화면 뜸 → **설치** 누르면 끝

👉 **[설치하기](https://github.com/imlikedott/zeta-counter/raw/refs/heads/main/zeta-counter.user.js)**

### 4. 사용 시작
제타 들어가면 {{char}} 말풍선 오른쪽 아래, 신고 버튼 왼쪽에 🔢 아이콘 생김
안 생기면 2번 허용 켰는지 다시 확인하고 제타 새로고침

## 🔒 개인정보

설정이랑 글자수 기록 전부 **내 브라우저 안에만** 저장됨. 대화 내용 밖으로 안 보냄

---

## ⚠️ 알아두기

- 글자수는 상태창(인포박스) **포함**해서 셈
- 스크립트 깔기 전 답변은 🔢 안 뜰 수 있음 → 수정 눌렀다 취소하면 뜸
- 제타가 화면 구조 바꾸면 안 먹을 수 있음 (업뎃 예정)
